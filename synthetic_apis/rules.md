# Synthetic API: Rules

The bot-driven rules engine lets a user compose if-this-then-that rules out of **phrases** that bot microservices declare at runtime.
A rule is made of one or more **triggers** ("When my 'Front Door' opens"), zero or more **states** ("while it is nighttime"), and one or more **actions** ("then notify people who live here").

The rules engine is provided by the `rules_engine` microservice package (or the reduced `free_rules_engine` package). Phrases are declared by the device-type and location rules microservices inside that package, so the exact set of phrases available in a location depends on the bot and the devices installed there.

Apps discover the available phrases from the `rule_phrases` state variable, build a rule from those phrases, send it in with the `set_rule` data stream message, and read the resulting rules back from the `rules` state variable.

## **Input** : Data Stream Messages

| Address | Description |
| ------- | ----------- |
| `set_rule` | Create or completely replace a rule. |
| `delete_rule` | Delete a rule. |
| `pause_rule` | Stop a rule from executing without deleting it. |
| `play_rule` | Resume execution of a paused rule. |

The `rule_id` is generated by the app (a UUID is recommended). Sending `set_rule` with an existing `rule_id` replaces that rule.

#### `set_rule` Content

| Property | Type | Description |
| -------- | ---- | ----------- |
| rule_id | String | Required. App-generated unique ID for this rule. |
| triggers | List | List of phrase objects of type trigger. At least one is required for the rule to be valid. |
| states | List | Optional list of phrase objects of type state. All states must be true when a trigger fires for the actions to execute. |
| actions | List | List of phrase objects of type action. At least one is required for the rule to be valid. |
| active | Boolean | Optional. Default is True. False creates the rule in a paused state. |

Each phrase object contains a `phrase_id` from the `rule_phrases` state variable, plus one key per parameter of that phrase. The key is the parameter's `name` and the value is the user's selection.

```
{
  "rule_id": "f1c7f1a2-3f0e-4b9b-9c9e-5b1d2a7c8e10",
  "triggers": [
    {
      "phrase_id": "entry_opened",
      "trigger_device_id": "00155F003468AFA0-039B"
    }
  ],
  "states": [
    {
      "phrase_id": "state_nighttime"
    }
  ],
  "actions": [
    {
      "phrase_id": "action_send_notification"
    }
  ],
  "active": true
}
```

Rule validation performed by the bot:
* A rule without any trigger or without any action is discarded.
* A phrase whose device parameter references a device that no longer exists in the location is removed from the rule.
* A phrase whose description still contains an unfilled `{}` after applying the parameters is removed from the rule.
* Rules are re-validated whenever a phrase is declared or removed by a microservice.

#### `delete_rule`, `pause_rule`, `play_rule` Content

```
{
  "rule_id": "f1c7f1a2-3f0e-4b9b-9c9e-5b1d2a7c8e10"
}
```

## Output

### State Variable : `rule_phrases`

Dictionary of the phrases currently available in this location, keyed by `phrase_id`. Internal function references (`eval`, `action`, `timer_eval`, `timer_init`) and the past-tense `past` text are stripped before publishing.

#### Phrase Properties

| Property | Description |
| -------- | ----------- |
| type | 0 = trigger, 1 = state, 2 = action. |
| device_types | List of device types this phrase applies to, if the phrase evaluates a device. |
| trigger | Triggers only. Type of trigger: `device_measurements_updated`, `mode_updated`, `occupancy_status_updated`, `recurring_schedule_trigger`, `oneshot_schedule_trigger`, `sunrise_fired`, `sunset_fired`, or a data stream address. |
| state | States only. Type of state to help native UI's render it, for example `time_range`. |
| title | Recommended section title. Group phrases with the same title under one section. |
| description | Description of the phrase in the user's language. Fill each `{}` with the parameter values in order. Triggers are full phrases; the app is expected to prefix states with "while" / "and" and actions with "and". |
| icon | Icon to render for this phrase. |
| parameters | List of parameter objects the user must fill out. |

#### Parameter Properties

| Property | Description |
| -------- | ----------- |
| name | Name of this parameter. Use it as the key in the phrase object sent with `set_rule`. |
| order | Optional. Parameters with higher numbers are filled out after lower numbers. |
| category | Type of input: 0 = Device ID; 1 = Text input; 2 = Absolute time-of-day (seconds from the start of the day); 3 = Relative time from now (seconds); 4 = Multiple-choice multi-select (list of ids); 5 = Multiple-choice single-select; 6 = Slider. |
| description | Short question or instruction to display to the user. |
| values | List of `{ "name": ..., "id": ... }` choices for device ID, multi-select, and single-select categories. Device ID choices also carry `icon` and `icon_font`. |
| value_type | 1 = int, 2 = float, 3 = string, 4 = list. |
| value | Default value, if applicable. |
| min_value | Slider minimum. |
| max_value | Slider maximum. |
| increment | Slider step. |
| unit | Optional unit of measurement for slider questions. |

### State Variable : `rules`

Dictionary of the rules in this location, keyed by `rule_id`. The bot republishes this state variable when a rule is set or deleted.

#### Rule Properties

| Property | Description |
| -------- | ----------- |
| triggers | List of trigger phrase objects exactly as sent in `set_rule`, minus any phrases that failed validation. |
| states | List of state phrase objects. |
| actions | List of action phrase objects. |
| active | True if this rule is currently executing. |
| description | Fully pieced together sentence with all parameters filled out, ending with a period. |
| trigger_desc | Trigger portion of the description only. |
| state_desc | State portion of the description only. |
| action_desc | Action portion of the description only. |
| trigger_icons | List of icons from the trigger phrases. |
| state_icons | List of icons from the state phrases. |
| action_icons | List of icons from the action phrases. |

Any additional top-level keys sent in the `set_rule` content are stored on the rule untouched, so apps can attach their own metadata.

#### `rules` JSON Content

```
{
  "value": {
    "f1c7f1a2-3f0e-4b9b-9c9e-5b1d2a7c8e10": {
      "triggers": [
        {
          "phrase_id": "entry_opened",
          "trigger_device_id": "00155F003468AFA0-039B"
        }
      ],
      "states": [
        {
          "phrase_id": "state_nighttime"
        }
      ],
      "actions": [
        {
          "phrase_id": "action_send_notification"
        }
      ],
      "active": true,
      "description": "When my 'Front Door' opens while It's nighttime, then Notify people who live here.",
      "trigger_desc": "When my 'Front Door' opens",
      "state_desc": "It's nighttime",
      "action_desc": "Notify people who live here",
      "trigger_icons": ["door-open"],
      "state_icons": [],
      "action_icons": []
    }
  }
}
```
